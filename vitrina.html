Витрина обликов

Википедия

Вид снят с en.wikipedia.org (обложка Vector 2022). Справочник: узкое левое оглавление, засечный заголовок, таблица с серой шапкой. Замер: текст 16/26, колонка 1117 px.

NCBI Bookshelf

Вид снят с ncbi.nlm.nih.gov/books (StatPearls). Медицинская база: полоса NIH, белый лист на сером поле, Times New Roman 16/22, коричневые заголовки, правая колонка панелями.

TeachMeAnatomy

Вид снят с teachmeanatomy.info. Учебный сайт для студентов-медиков: чёрная шапка, бирюзовый акцент, крошки, полужирное оглавление слева. Текст 16/28.

Radiopaedia

Вид снят с radiopaedia.org. Фиолетовая шапка с разрядкой, белый лист на тёмном поле, плотный текст 13/19.5, плитки рисунков справа.

MkDocs Material

Вид снят с squidfunk.github.io/mkdocs-material. Самый распространённый вид документации: три колонки, индиговый акцент, врезки с цветной полосой.

MkDocs Material, тёмная

Вид снят с squidfunk.github.io/mkdocs-material. Та же тема в тёмном режиме — ровно так она и снята замером: фон #1e2129. Для вечернего чтения.

Notion

Вид снят с notion.com/help. Документ, а не сайт: крупный заголовок 42 px, меню слева, никакой правой колонки, много воздуха.

Stripe Docs

Вид снят с docs.stripe.com. Эталон технической документации: ссылки #5469d4, текст #3c4257, плотная навигация, правое оглавление.

OpenStax

Вид снят с openstax.org (учебники). Настоящий электронный учебник: широкая панель оглавления книги, серо-графитовые заголовки.

Osmosis

Вид снят с osmosis.org. Синий баннер, скруглённые карточки с тонкой рамкой, левая панель тем, кнопки-таблетки.

Merck Manual

Вид снят с merckmanuals.com/professional. Профессиональный справочник: белая шапка, бордовые ссылки #b12e32, серое поле вокруг листа.
